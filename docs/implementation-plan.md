# خطة إكمال مكتبي

هذه قائمة قبول قابلة للتتبع، وليست إعلاناً باكتمال المنتج. لا تُعد الوحدة مكتملة لمجرد وجود نوع بيانات أو شاشة. كل بند يحتاج حفظاً دائماً، تحققاً من المدخلات، ربطاً ببقية الوحدات واختباراً.

## الترتيب

1. **الأساس:** معاملات حفظ آمنة عند الفشل، ترحيل الإصدارات، نسخ احتياطي واستعادة، إعدادات المكتب، تسجيل دخول بالهاتف، هوية المستخدم والصلاحيات والتشفير.
2. **القضايا:** قوالب مراحل حسب النوع، حفظ مرجع كل جهة، بيانات الشرطة والنيابة والمحاكم والمسجلين، متطلبات كل مرحلة، تعديل القوالب، انتقالات وسجل نشاط.
3. **المواعيد والمستندات:** جلسات ونتائجها، مواعيد مستقلة وقواعد مدد يراجعها المحامي، تقويم، تذكير واتساب، تصوير وPDF وOCR وبحث.
4. **الحسابات:** اتفاقات بمراحل واستحقاق، دفعات وأرقام إيصالات سنوية، إلغاء دون حذف، PDF، مصروفات وأمانات وكشوف حساب.
5. **التوثيقات:** أطراف ورقم سنوي، وثائق، سجل وبحث وتصدير وإلغاء وربط مالي.
6. **المعرفة:** مكتبة بمصادر وحقوق موثقة، حفظ مرجع للقضية، صيغ وملء بيانات وتصدير.
7. **الخدمات:** مساعد يستند إلى المصادر مع موافقة على إرسال البيانات، خادم وصلاحيات ومزامنة، باقات وتجديد وفترة سماح.
8. **القبول:** اختبار عميل جديد وقضايا بأنواع مختلفة، جميع الحركات المالية، إعادة التشغيل، فشل التخزين، العمل دون اتصال، ثم اختبار هاتف فعلي.

## ما تحقق قبل هذه الخطة

- واجهة عربية RTL وتسجيل دخول تجريبي بحقل هاتف.
- إضافة وتعديل العميل والقضية وربط عدة أطراف.
- مسار محلي: موعد، مرفق، اتفاق أتعاب، دفعة وإيصال داخل التطبيق، ملاحظة وإغلاق.
- حفظ محلي متسلسل مع تراجع عند فشل الكتابة؛ 18 اختباراً آلياً ناجحاً.

## اعتماديات خارجية

مصادر القوانين والسوابق وحقوق نشرها، استضافة واسم نطاق، حسابات مزودي WhatsApp والذكاء الاصطناعي والدفع، وأجهزة فعلية لاختبار الكاميرا والإشعارات. لا تحل البيانات التجريبية محل هذه المتطلبات، ولا تعني شاشة إعدادات أن التكامل يعمل.
